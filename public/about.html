Le projet

InflatioConvert est une application web de conversion de devises enrichie d'une dimension économique : l'historique de l'inflation en zone euro depuis 1991, basé sur les données officielles IPCH de la Banque Centrale Européenne (BCE) via Eurostat.

L'application intègre l'API Claude d'Anthropic pour générer des analyses économiques contextualisées sur chaque conversion ou période d'inflation sélectionnée.

Le déploiement est réalisé sur Microsoft Azure à l'aide d'un Codespace GitHub connecté à un conteneur Node.js/Express avec une base MongoDB pour la persistance des données.

Node.js Express.js MongoDB Microsoft Azure Claude API (Anthropic) BCE / Eurostat IPCH GitHub Codespaces Chart.js

Sources des données

Les taux d'inflation sont issus de la série officielle IPCH (Indice des Prix à la Consommation Harmonisé) publiée par Eurostat et la BCE, code de série prc_hicp_ainr. Ces données couvrent la zone euro de 1991 à 2025 et sont mises à jour annuellement.

Les taux de change affichés dans le convertisseur sont des estimations générées par IA à titre indicatif et ne constituent pas des données financières certifiées. Pour des opérations financières réelles, consultez un prestataire de services de change agréé.
